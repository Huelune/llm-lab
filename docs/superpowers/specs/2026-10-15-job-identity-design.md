# 작업 UUID · 이름 · 설정 기록 설계

- 작성일: 2026-10-15
- 상태: 구현됨 (2026-10-15)
- 바탕: `2026-10-15-llm-connections-design.md`

## 1. 목표

- 작업 ID를 UUID로 바꾼다(DB 키, 주소, 대화 기록 파일 이름, 점검 스크립트 모두). 1, 2, 3 같은 번호는 쓰지 않는다.
- 작업에 이름을 두고 화면에서 바꿀 수 있게 한다.
- 작업을 만들 때의 설정(연결, 모델 등)을 작업에 기록하고, 작업 화면과 작업 목록에 보인다.

## 2. 작업 ID

- `jobs.id`는 `uuid4()` 문자열(소문자, 하이픈 포함 36자). `rows.job_id`, `files.job_id`, `definitions.job_id`도 같은 문자열.
  행 ID(`rows.id`)는 지금처럼 정수(화면 안의 앵커·체크박스용)다.
- 작업 순서는 `created_at`(ISO 시각) 내림차순, 같으면 삽입 순서(`rowid`).
- 주소: `/results/{uuid}`, `/results/{uuid}/summary`, `/results/{uuid}/fixes.patch`, `/results/{uuid}/results.xlsx`,
  `/results/{uuid}/stop`, `/results/{uuid}/retry`, `/results/{uuid}/rename`, `/api/results/{uuid}`. 없는 UUID는 404.
- 대화 기록 파일 이름: `{시각}_job{uuid}_row{엑셀행}.md`.
- 점검 스크립트(`peek_logs.py`, `peek_job.py`)의 `--job`은 UUID 전체나 앞부분(4자 이상, 하나로만 맞을 때)을 받는다. 여러 개가
  맞거나 없으면 "작업을 찾지 못했습니다" / "여러 작업이 맞습니다. 더 길게 적으세요"를 찍는다. 빼면 가장 최근 작업. 화면에는
  작업을 ID 앞 8자로만 가리킨다.
- 스키마 6. 예전 형식 DB(스키마 5 이하)를 열면 `StoreError("예전 작업 기록 형식입니다. uv run llm-fix-server --clear all 뒤
  다시 켜세요.")`로 멈춘다(옮기지 않는다). `--clear all/cache`는 예전 DB에서도 동작해야 한다. 캐시 표는 그대로 쓸 수 있다.

## 3. 작업 이름

- `jobs.title`. 기본값은 `"{엑셀 파일 이름} · {시트 종류 화면 이름}"`.
- 작업 화면 제목 옆 "이름 바꾸기"(접기 양식, `POST /results/{uuid}/rename`, 1~80자, 앞뒤 공백 정리, 빈 이름이면 오류 안내).
  다른 사이트에서 보낸 요청은 지금 미들웨어가 거부한다.
- 최근 작업(첫 화면), 작업 목록, 작업 화면 제목, 브라우저 탭 제목이 이 이름을 쓴다.

## 4. 작업 설정 기록

- `jobs.settings`(JSON 문자열). 작업을 만들 때 채운다:
  `{"connection": 이름, "model": 모델, "kind": 종류 이름, "mode": 처리 방식 값 또는 "", "choices": [고른 대상...],
  "follow_ups": 되묻기 횟수, "source_root": 소스 폴더, "excel": 엑셀 파일 이름}`. 키는 들어가지 않는다.
- 작업 화면 맨 위 "작업 설정" 카드: 연결, 모델, 시트 종류, 처리 방식(라벨), 분석 대상, 되묻기 횟수, 소스 폴더, 엑셀 파일, 시작 시각.
  값이 없는 칸은 "-".
- 첫 화면의 최근 작업과 작업 목록 표: 이름, 종류, 연결, 모델, 시작 시각, 진행(지금 쓰는 진행 표시).
- `jobs.connection`은 지금처럼 두고(worker가 쓴다), settings의 connection과 같은 값으로 채운다.

## 5. 캡처 주의

모델 이름은 회사 정보다. 최근 작업·작업 목록·작업 화면에는 사용자가 요청해 보이지만, 캡처용 요약 페이지에는 넣지 않는다.
요약 페이지 제목은 작업 이름(엑셀 이름이 들어간다) 대신 `작업 요약 · {종류} · {ID 앞 8자}`.

## 6. 테스트

- UUID 키로 만들기·읽기·목록 순서·행·파일·정의, 예전 형식 DB 거절, 예전 DB에서 `--clear all`.
- 웹: UUID 주소로 작업 화면·요약·패치·엑셀·멈춤·다시 시도·이름 바꾸기, 없는 UUID 404, 숫자 주소 404.
- 설정 카드·목록 칸, 요약 페이지에 모델·연결·작업 이름이 없음.
- 대화 기록 파일 이름, peek 스크립트의 UUID 앞부분 찾기·여러 개 맞음·없음, 화면에 `secret` 없음.
